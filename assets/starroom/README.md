# 슈국 스타룸 이미지

이 폴더는 학생 스타룸 프로젝트의 이미지 원본과 확정 소재를 보관합니다.
사용자 요청(2026-10-30)에 따라 앞으로 이 프로젝트에서 만드는 이미지도 이 경로 아래에 저장합니다.

## 폴더와 파일 규칙

- characters/: 학생 캐릭터
- rooms/: 방 배경
- furniture/: 가구와 소품
- previews/: 화면 시안
- 파일명은 영문 소문자와 하이픈을 사용하고 v01, v02처럼 버전을 붙입니다.
- 수정본은 새 파일로 저장하여 이전 버전을 보존합니다.
- 이미지 저장만으로 학생 페이지에 자동 적용하지 않습니다. 화면 연결은 별도 작업입니다.
- 학생 개인정보, 개인 접근 링크, 비밀키를 이미지나 문서에 포함하지 않습니다.
