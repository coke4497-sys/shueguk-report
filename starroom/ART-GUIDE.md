# 스타룸 그림 지침 (코덱스·클로슈 공용)

학생 페이지의 '나만의 스타룸'에 들어가는 방 배경과 가구 그림의 규칙이다.
그림은 **SVG 소재**로만 만든다. AI 이미지(사진·PNG)는 쓰지 않는다 — 색 다섯 가지를 바꿔 쓰려면 색 칸을 비워 둔 SVG여야 한다.

## 느낌
- **치유·힐링 게임처럼 부드럽고 무해하게** (원장님 지시, 2026-10-20).
- 진한 외곽선 없음. 모서리는 둥글게(같은 색 테두리 `stroke-linejoin="round"`로 둥글리는 방식을 써도 된다).
- 파스텔 톤, 낮은 대비. 그림자는 바닥에 번지는 부드러운 타원 하나.
- 가구에 얼굴·표정은 넣지 않는다(차분하게). 작은 장식(쿠션, 화분, 별 무늬 등)은 좋다.
- 이모지·글자·로고·실존 상표는 넣지 않는다.

## 시점과 크기 — 모든 아이템이 같아야 한다
- 2:1 아이소메트릭. 오른쪽 축 = (1, 0.5), 왼쪽 축 = (−1, 0.5). 위로 = (0, −1).
- **빛은 왼쪽 위에서**: 윗면 = 가장 밝게(`--sr-top`), 왼쪽 앞면 = 기본(`--sr-base`), 오른쪽 앞면 = 그늘(`--sr-shade`).
- 아이템 SVG의 `viewBox="-60 -100 120 130"`(고정). **원점 (0,0) = 아이템이 바닥에 닿는 발자국의 한가운데.** 방에 놓을 때 이 점을 배치 지점에 맞춘다.
- 가구가 차지하는 크기는 지금 임시 그림과 비슷하게 맞춘다(소파 가로 약 ±48, 책장 높이 약 85). 틀 밖으로 나가지 않는다.
- 책상 윗면 높이는 **33**(원점에서 위로 33). 탁상 조명은 이 높이에 올라간다 — 책상을 새로 그려도 윗면 높이는 33으로 둔다.
- 방 배경 `room.svg`의 `viewBox="0 0 320 260"`, 바닥 마름모 꼭짓점 왼(20,180)·위(160,110)·오른(300,180)·아래(160,250). 배치 지점 좌표는 `catalog.json`의 `spots`. 아이템은 방 안에서 0.85배로 그려진다.

## 색 칸 — 고른 색으로 바뀌는 부분
아이템 SVG는 색을 직접 쓰지 않고 다섯 칸만 쓴다. 화면이 학생이 고른 색(크림·세이지·연분홍·하늘색·차콜)으로 채운다.

| 칸 | 쓰는 곳 |
|---|---|
| `var(--sr-top)` | 윗면·밝은 면 |
| `var(--sr-base)` | 기본 면 — **반드시 쓴다** |
| `var(--sr-shade)` | 그늘 면·다리·받침 |
| `var(--sr-line)` | 서랍 선·손잡이 같은 가는 디테일(진하지 않게, opacity로 연하게) |
| `var(--sr-hi)` | 작은 반짝임·하이라이트 |

색이 바뀌지 않는 장식(조명 빛, 책 등, 화분, 쿠션의 별 무늬, 그림자)은 아래 고정 색만 쓴다:
`#FFFFFF #FFF1C2 #FFF4CF #FFF6E2 #FFF6DA #FFE29A #FFD978 #F4C76A #F8E7BF #D3E3F2 #F4D3D6 #F6D3D5 #F6C9CC #CFE2D6 #E9C9A6 #9CC2A4 #7A6450`
(늘려야 하면 `tools/starroom-art-check.js`의 `DECO`와 이 목록을 함께 고친다.)

## 파일 규칙
- 아이템: `starroom/items/<아이템>-<모양>.svg` — desk·chair·sofa·shelf·lamp·rug × A·B, 12개. **파일 이름과 `catalog.json`의 아이템·모양·색 ID는 바꾸지 않는다**(학생 배치 기록의 열쇠). 그림만 갈아 끼운다.
- 모양 A·B의 뜻은 `catalog.json`의 `label` 그대로(예: 의자 A = 등받이 의자, B = 둥근 스툴).
- 쓰지 않는 것: `<script>`, `<image>`, `<text>`, `<foreignObject>`, 외부 링크(`href`), `on…` 속성, `<animate>`. 아이템 파일에는 `<style>`도 쓰지 않는다(방 배경만 별 반짝임용 `<style>` 허용).
- `id`는 써도 된다(그림자 블러 필터 등). 화면이 한 페이지에 여러 번 넣을 때 자동으로 바꾼다.
- 파일 하나 20KB 이하.
- 방 배경의 벽·바닥 색은 `var(--sr-wall-l, #…)`처럼 **기본값을 단 칸**으로 둔다(나중에 벽지·바닥 바꾸기용).

## 확인
1. `node tools/starroom-art-check.js` — 규칙 검사. 통과해야 한다.
2. `starroom/preview.html` — 60가지 조합과 예시 방 3개. 로컬에서는 저장소 폴더에서 `python3 -m http.server` 뒤 `/starroom/preview.html`.
   색 다섯 가지 모두에서 면이 구분되는지, 차콜에서 너무 어둡지 않은지, 방 안에서 크기·바닥 위치가 맞는지 본다.
